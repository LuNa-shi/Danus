# Share project access between the two V1 operators

**Status: Accepted for V1**

V1 will treat the two trusted operators as sharing access to all Projects: either operator may view and manage a Project, use its Project File Library, converse with its Main Agent, and control its run lifecycle. V1 will use simple application-password authentication rather than project invitations or per-project authorization; richer identity and authorization can be added if the console is later packaged for broader use.
