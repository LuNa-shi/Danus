# Give the Main Agent a manifest and read files explicitly

**Status: Accepted for V1**

When a Project Main Agent Session is activated, the Web Console will provide a Project File Manifest for the Project Context Directory. The manifest describes available versions and processing states but does not claim that their contents were read. Files selected with a natural-language message are explicit Conversation Attachments and should be read first; the Main Agent may read other project files when the research requires it. Uploading or updating a file remains storage-only and neither activates nor interrupts the Session.
